# dot-files

Config for **miskatonic** — the CachyOS (Arch) desktop. Arch is imperative,
so this repo can't *be* the machine the way [personal-server](https://github.com/FelipeAfonso/personal-server)
is for rlyeh — instead it tracks the machine's real state (configs, explicit
packages, enabled services) and replays it: the deploy commands are
`./export_current` and the install runbook below.

Fleet canon: `rlyeh` (server, [personal-server](https://github.com/FelipeAfonso/personal-server)) ·
`miskatonic` (this desktop) · MacBook TBD.

```
import_current / export_current   copy-based sync: machine → repo / repo → machine
pkglist-native.txt / -aur.txt     pacman -Qqen / -Qqem dumps (regenerated by import)
services.txt                      enabled systemd units, system + user (regenerated by import)
setup-storage.sh                  fstab entry + ~/media symlink for the 4 TB NTFS drive
etc/                              hand-edits under /etc: sddm autologin+theme, swappiness, paru
bin/                              ~/.local/bin: review, unreview, secrets-pull, t3code launchers
systemd/user/                     custom user units: t3code server, appimagekit entry hider
hypr/ waybar/ dunst/ rofi/        Hyprland desktop (hyprland.lua — native Lua config, ≥0.55)
wallust/                          theming hub: wallpaper → wallust → every app's colors
ghostty/ tmux/ zsh/ starship/     terminal stack (ghostty auto-attaches tmux session "main")
nvim/                             clean-slate 0.12 config, vim.pack + lockfile, no Mason
lazygit/ opencode/                git UI + agent
git/ gtk-3.0/ gtk-4.0/ btop/      the long tail, incl. mimeapps.list, user-dirs.dirs,
MangoHud/ xkb/                    custom XKB layout "cust"
```

## Design decisions (short version)

- **Copy, don't symlink.** `export_current` copies repo → `~/.config`;
  `import_current` copies live state back and strips machine junk. Edits made
  live are not in the repo until an import runs. Crude, but every file stays a
  plain file — nothing depends on stow or a symlink farm surviving.
- **The lists are generated, not curated.** pkglists and services.txt are
  dumps of what is actually installed/enabled, refreshed by `import_current`.
  If a package matters, install it — the next import records it.
- **Theming is one pipeline.** Pick a wallpaper (`SUPER+W`) → wallust renders
  `wallust/templates/` → configs under hypr/waybar/dunst/rofi/ghostty/tmux/
  zsh/opencode/nvim pick up the palette → `hypr/scripts/apply-theme.sh`
  reloads everything. The generated color files are committed on purpose:
  current wallpaper state is part of the machine.
- **Secrets** live in the private, sops/age-encrypted
  [secrets](https://github.com/FelipeAfonso/secrets) repo, one file per host.
  `bin/secrets-pull` decrypts `miskatonic.yaml` into
  `~/.config/zsh/.secrets.env` (0600, gitignored), which `.zshrc` exports into
  the environment. This repo stays public and credential-free.

## Install (fresh CachyOS)

1. CachyOS installer: hostname `miskatonic`, user `felipe`, btrfs + limine
   defaults. Boot it.
2. Clone and install packages (paru is in the native list, CachyOS repos
   carry it):

   ```sh
   git clone https://github.com/FelipeAfonso/dot-files ~/code/personal/dot-files
   cd ~/code/personal/dot-files
   sudo pacman -S --needed - < pkglist-native.txt
   paru -S --needed - < pkglist-aur.txt
   ```

3. Apply configs and units: `./export_current`, then enable everything in
   `services.txt` (`sudo systemctl enable <unit>` / `systemctl --user enable
   <unit>`) and copy the `/etc` hand-edits:

   ```sh
   sudo cp etc/sddm.conf /etc/sddm.conf
   sudo cp etc/sysctl.d/99-swappiness.conf /etc/sysctl.d/
   sudo cp etc/paru.conf /etc/paru.conf
   ```

4. Storage: plug the 4 TB NTFS drive, `sudo ./setup-storage.sh` (verify the
   UUID at the top of the script against `lsblk -f` first). Wallpapers live
   at `~/media/wallpapers`, so theming half-works until this is done.
5. tmux plugins: `git clone https://github.com/tmux-plugins/tpm
   ~/.config/tmux/plugins/tpm`, then `prefix + I` inside tmux.
   Editor toolchain: `./nvim/bootstrap.sh` (LSPs via paru + bun).
6. Secrets: restore the age key, then decrypt (see below).
7. Sign-ins: `gh auth login` (git credentials ride gh, see `git/config`),
   `sudo tailscale up`, `claude`, Insync, Steam. Device-code flows all work
   the same way: run, open URL, approve.
8. Reboot — SDDM autologs into Hyprland.

Known manual gaps (not in any list): the SDDM "silent" theme
(`/usr/share/sddm/themes/silent`, no package owns it), ckb-next + OpenLinkHub
RGB profiles, AppImages under `~/Applications` (T3 Code, OpenWhispr, Awakened
PoE Trade), kwallet contents.

## Secrets (one-time bootstrap)

The personal age key at `~/.config/sops/age/keys.txt` is the root secret: it
decrypts every host file in the secrets repo. Generate it once
(`age-keygen -o ~/.config/sops/age/keys.txt`), back it up somewhere that is
not a git repo, and restore it on any machine that needs to read secrets.

```sh
git clone git@github.com:FelipeAfonso/secrets.git ~/code/personal/secrets
sops ~/code/personal/secrets/miskatonic.yaml   # create/edit (encrypts on save)
secrets-pull                                   # → ~/.config/zsh/.secrets.env
exec zsh                                       # env vars are now exported
```

Keys in `miskatonic.yaml` are UPPER_SNAKE (`ANTHROPIC_API_KEY: sk-ant-…`)
because they land in the shell environment verbatim — see
`miskatonic.yaml.example` in the secrets repo. Rotate by editing with `sops`
and re-running `secrets-pull`.

## Day-to-day

- Machine changed → `./import_current`, review the diff, commit. Repo
  changed → `./export_current` (nvim note: the live config is a plain copy,
  so edit here and export — not the other way).
- `./import_current` regenerates pkglists/services.txt, so package installs
  and `systemctl enable` show up in the diff for free.

## Validation

After an export: `zsh -ic exit` (shell loads), `nvim --headless +q` (config
loads, plugins restore from `nvim-pack-lock.json`), `hyprctl reload` (no
config errors), `bash -n` the touched scripts. After a fresh install, the
smoke test is the reboot: SDDM → Hyprland → waybar/dunst up, `SUPER+O` opens
ghostty attached to tmux, `SUPER+W` themes the world.

# personal-laptop

Config for **yuggoth** — the MacBook Air. Forked from
[personal-desktop](https://github.com/FelipeAfonso/personal-desktop)
(miskatonic) with the Linux desktop layer stripped out and the parts that
matter ported to macOS: the terminal stack survives intact, the custom XKB
layout's job goes to Karabiner, and pacman's job goes to Homebrew. This is a
deliberately lighter port — no tiling WM, no wallust theming pipeline.

Fleet canon: `rlyeh` (server, [personal-server](https://github.com/FelipeAfonso/personal-server)) ·
`miskatonic` (desktop, [personal-desktop](https://github.com/FelipeAfonso/personal-desktop)) ·
`yuggoth` (this laptop).

```
import_current / export_current   copy-based sync: machine → repo / repo → machine
Brewfile                          brew bundle dump (regenerated by import)
bin/                              ~/.local/bin: review, unreview, secrets-pull
karabiner/                        keyboard remaps (the XKB layout's successor)
ghostty/ tmux/ zsh/ starship/     terminal stack (ghostty auto-attaches tmux session "main")
nvim/                             clean-slate 0.12 config, vim.pack + lockfile, no Mason
lazygit/ opencode/                git UI + agent
agents/                           global agent prompts (one per CLI + shared model table + yuggoth
                                  notes; export generates ~/.claude/CLAUDE.md, ~/.codex/AGENTS.md,
                                  ~/.config/opencode/AGENTS.md), vendored skills, unslop hooks
git/ btop/                        the long tail
assets/icons/                     project icon candidates (gallery.html to browse)
```

## Design decisions (short version)

- **Copy, don't symlink.** Same as the desktop: `export_current` copies
  repo → `~/.config`; `import_current` copies live state back and strips
  machine junk. Every file stays a plain file.
- **The Brewfile is generated, not curated.** `import_current` runs
  `brew bundle dump`. If a package matters, install it — the next import
  records it.
- **No theming pipeline.** miskatonic's wallpaper → wallust machinery stays
  on miskatonic; here everything runs stock colors (nvim uses a builtin
  colorscheme).
- **Agent config is generated, shared with the fleet.** `export_current`
  concatenates `agents/<cli>-global.md` and `agents/models.md` (the sections
  shared with rlyeh and miskatonic, kept in sync by hand with
  personal-server's `home/felipe/agents/*.md` and personal-desktop's
  `agents/*.md`) with `agents/yuggoth-agents.md` (this machine, the tailnet,
  how to operate the fleet) into each CLI's global prompt file. Edit the repo
  files and re-export; never the generated ones. Skills (`agents/skills/`)
  and the unslop hook scripts (`agents/hooks/`) are vendored and installed
  the same way. The unslop hooks block in `~/.claude/settings.json` is the
  one by-hand piece (Claude Code rewrites that file at runtime):

  ```json
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command",
      "command": "bash ~/.claude/hooks/unslop-reminder.sh", "timeout": 10 }] }],
    "Stop": [{ "hooks": [{ "type": "command",
      "command": "python3 ~/.claude/hooks/unslop-stop-gate.py", "timeout": 15,
      "statusMessage": "Checking unslop compliance" }] }]
  }
  ```
- **Secrets** live in the private, sops/age-encrypted
  [secrets](https://github.com/FelipeAfonso/secrets) repo, one file per host.
  `bin/secrets-pull` decrypts `yuggoth.yaml` into
  `~/.config/zsh/.secrets.env` (0600, gitignored), which `.zshrc` exports
  into the environment. This repo stays public and credential-free.

## Install (fresh macOS)

1. Name the machine (System Settings does only the first one):

   ```sh
   sudo scutil --set ComputerName yuggoth
   sudo scutil --set LocalHostName yuggoth
   sudo scutil --set HostName yuggoth
   ```

2. Install [Homebrew](https://brew.sh), then clone and install packages:

   ```sh
   git clone https://github.com/FelipeAfonso/personal-laptop ~/code/personal/personal-laptop
   cd ~/code/personal/personal-laptop
   brew bundle --file=Brewfile
   ```

3. Apply configs and pull secrets:

   ```sh
   ./export_current
   git clone git@github.com:FelipeAfonso/secrets.git ~/code/personal/secrets
   secrets-pull
   ```

4. tmux plugins: `git clone https://github.com/tmux-plugins/tpm ~/.config/tmux/plugins/tpm`,
   then `prefix + I` inside tmux.
5. nvim language tooling: `./nvim/bootstrap.sh` (needs bun).
6. Grant Karabiner-Elements its input-monitoring permissions on first launch.
